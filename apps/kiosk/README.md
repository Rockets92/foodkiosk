# App kiosk

App Flutter del totem: schermata di attesa, lingua e "mangio qui / porto
via", menu per categorie, dettaglio prodotto con allergeni e
personalizzazioni, carrello, pagamento e numero d'ordine. Vedi il README
principale per l'avvio completo.

```sh
flutter run -d windows                                   # totem Windows
flutter run -d chrome --dart-define=SERVER_URL=http://localhost:8080/
flutter test
```
